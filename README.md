Carnet de bord — Apprentissage de Git et GitHub
Présentation
Ce dépôt contient les notes et les exercices réalisés pendant mon apprentissage de Git et GitHub.
Objectifs
- Apprendre à utiliser Git Bash.
- Comprendre le fonctionnement d'un dépôt local.
- Suivre les modifications avec git status.
- Préparer les modifications avec git add.
- Enregistrer les modifications avec git commit.
- Consulter l'historique avec git log.
- Relier un dépôt local à un dépôt distant sur GitHub.
- Envoyer les modifications avec git push et git pull
Fichiers du projet
- carnet.md 
- memo-terminal.md 
Travail réalisé
J'ai créé un dépôt Git local, ajouté des notes dans mes fichiers, enregistré mes modifications avec des commits et envoyé mon travail sur GitHub avec git push.
 Conclusion
Ce projet m'a permis de pratiquer les principales commandes Git et de comprendre comment envoyer les modifications d'un dépôt local vers GitHub. et vise versa
