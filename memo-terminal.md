pwd: qui permet d'afficher le chemin du dossier dans lequel je me trouve
cd: permet de changer dans le terminal
ls : permet d'afficher les fichiers et dossiers du repertoire
cat : permet d'afficher le contenu d'un fichier texte dans le terminal
mkdir : permet de creer un nouveau dossier
touch : permet de creer un fichier 
rm : permet de supprimer un fichier mais il faut l'utiliser avec prudence
git push :envoie les commit vers github
git remote add origin : permet de relier un depôt local a un depôt distant
git show head: affiche le contenu du fichier enrigistre dans le deriere commit
un depôt local se trouve sur mon ordinateur
le depôt distant se trouve sur githup
git add :prepar les modifications
git commit enrigistre les modification
nano: permet d'ajouter des modification, corriger et supprimer des texte
