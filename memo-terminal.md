pwd: qui permet d'afficher le chemin du dossier dans lequel je me trouve
cd: permet de changer dans le terminal
ls : permet d'afficher les fichiers et dossiers du repertoire
cat : permet d'afficher le contenu d'un fichier texte dans le terminal
mkdir : permet de creer un nouveau dossier
touch : permet de creer un fichier 
rm : permet de supprimer un fichier mais il faut l'utiliser avec prudence
